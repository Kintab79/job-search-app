# مساعد البحث عن وظيفة (أندرويد)

تطبيق يعمل بدون إنترنت وبدون أي API. بياناتك تبقى في جوالك فقط.

## الميزات
- سيرة ذاتية: رفع سيرتك الحالية أو إنشاء جديدة (مع فحص المصداقية، وتصدير Word)
- معايير البحث وقائمة التنبيهات
- تقييم الإعلانات: مناسبة / تحتاج قرارك / غير مناسبة
- متتبع الطلبات
- تجهيز التقديم (خطاب تغطية، بنك إجابات، قائمة فحص قبل التقديم)

## بناء ملف APK
1. ارفع هذا المجلد إلى مستودع GitHub خاص.
2. افتح تبويب Actions ثم Build APK ثم Run workflow.
3. بعد انتهاء البناء نزّل الملف من Artifacts: job-search-assistant-apk.

## التثبيت على الجوال
انقل app-debug.apk للجوال، افتحه، واسمح بالتثبيت من مصدر غير معروف عند الطلب.

## تجربة سريعة على الكمبيوتر
شغّل داخل مجلد www: python3 -m http.server 8765 ثم افتح localhost:8765
